# ⚽ Football Manager 2027 - Hub & Manager Story

Willkommen im Repository meiner Football Manager 2027 Webseite. Auf dieser Plattform erstelle und veröffentliche ich meine FM27 Manager-Storys, Stelle Taktiken (`.fmf`) sowie Standardvarianten zum Download bereit und teile Media-Packs sowie Config-Dateien.

---

## 🎨 Tech-Stack & Features

* **Framework:** [Astro](https://astro.build/) (Static Site Generator)
* **Styling:** Tailwind CSS (Custom Dark-Mode Farbschema)
* **Hosting:** GitHub Pages (Automatisierter Deployment-Workflow via GitHub Actions)
* **Design & Theme:** Custom FM-Optik (Royal Blue, Hot Magenta, Gold)

---

## 🛠️ Lokale Entwicklung

Voraussetzung ist eine installierte [Node.js](https://nodejs.org/)-Umgebung (Version 20+).

```bash
# 1. Repository klonen
git clone [https://xburzelx.github.io/football-manager-27](https://xburzelx.github.io/football-manager-27)

# 2. In das Projektverzeichnis wechseln
cd football-manager-27

# 3. Abhängigkeiten installieren
npm install

# 4. Lokalen Dev-Server starten (erreichbar unter http://localhost:4321)
npm run dev
